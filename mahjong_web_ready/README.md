# 友達とリーチ麻雀 v3.1 — 緑の麻雀卓UI改良版

## ローカル起動
Node.js LTSをインストール後、このフォルダで実行します。

```bash
npm install
npm start
```

ブラウザで http://localhost:3000 を開きます。

## Render公開
1. ZIPを解凍し、中身をGitHubリポジトリへアップロード
2. Renderで New → Web Service を選び、GitHubリポジトリを接続
3. Build Command: `npm install`
4. Start Command: `npm start`
5. デプロイURLを友達に共有

## 今回の変更

- リーチ、門前清自摸和、七対子、断么九、役牌、混老頭、混一色、清一色の簡易役判定を追加

## 重要な制限
これはルール判定を改善した試作版であり、競技用の完全な日本式リーチ麻雀エンジンではありません。符計算・正確な翻計算、ドラ/赤ドラ、ポン/チー/カン、フリテンと待ちの完全判定、ロンの選択UI、流局時の聴牌料、親子別支払い、連荘・積み棒、役満などは未実装または簡略化されています。正確な対局には、これらのルールと十分なテストを追加する必要があります。

## v2.2 修正

## 鳴き機能について
現在は基本的なポン・チー・大明槓の簡易実装です。鳴きの優先順位（ロン優先など）、加槓・暗槓、槓ドラ、フリテン・役判定との完全連携は未完成で、競技用の完全な日本式リーチ麻雀ルールではありません。CPUは鳴きを簡易的に判断します。

## v2.6 更新（対局ルール設定・持ち点）
- ルーム作成画面に「対局ルール設定」を追加。4人麻雀/3人麻雀、東風戦/半荘戦、開始点数25,000/30,000/35,000点を選択できます。
- 選択したルールをルームに保存し、参加者全員のロビーに表示します。
- 開始点数を全プレイヤーとCPUに反映し、対局中の点数を点数一覧に表示します。
- 3人麻雀では萬子の2〜8を山から除き、チーを禁止。CPU追加・参加上限・手番進行を3人用に対応しました。
- 東風戦は東場、半荘戦は東場から南場へ進む局進行を追加しました。

## v2.6の制限
この更新はルーム設定と基本的な3人/4人進行の実装です。3人麻雀特有の正式な点数計算（ツモ損/北抜き等のルール選択）、厳密な親子別支払い、全局面での局終了・連荘条件、全ルールの自動テストは未完成です。持ち点は開始値と現在値の表示・更新に対応していますが、競技用の完全な麻雀エンジンではありません。

## v2.8 追加：三人麻雀の北抜き

- 三人麻雀で、自分の手番に北を持っていると「北抜き」ボタンを表示します。
- 北を手牌から抜き、山から補充牌を引きます。抜いた北は手牌と分けて表示します。
- 抜いた北1枚につき抜きドラ1翻相当として点数計算に加算します。
- リーチ後は、直前に引いた牌が北の場合のみ北抜きできます。
- CPUも三人麻雀で北を持っている場合、条件を満たせば自動で北抜きを行います。
- 北抜き後に補充牌がない場合は流局処理になります。

北抜きの細かな扱いは採用ルールによって異なります。この実装は北抜き＝抜きドラ、補充牌は山から引く方式です。

## v3.6 役判定の全面修正
テスト（`yaku_tests/`）で見つかった不具合を修正しました。
- 和了判定が手牌の並び順に依存していた不具合を修正（ツモ・ロン・リーチ・フリテン・流局テンパイに影響）。
- 国士無双（十三面待ち含む）が成立しなかった不具合を修正。
- 役判定を作り直し：副露した面子も判定対象にし、待ちの形（両面・辺張・嵌張・単騎・シャンポン）ごとに最高得点の解釈を採用。
  - 平和（待ち・雀頭の判定）、対々和、三色同順・同刻、一気通貫、小三元、混全帯么九／純全帯么九、三暗刻（ロンで完成した刻子は明刻）を修正。
  - 役牌は1組ごとに1翻、自風＝場風の刻子は2翻。二盃口と一盃口・七対子の重複を解消。混老頭と混全帯么九の重複を解消。
- 符計算：待ち（嵌張・辺張・単騎）の+2符、副露・大明槓の符、ロンで完成した刻子の明刻扱い、副露ロンの30符最低を実装。
- 新たに対応した役：ダブル立直、嶺上開花、海底摸月、河底撈魚、三槓子、四槓子、地和。
- リーチ：一発は自分の次の打牌で消える。リーチ後はツモ切りのみ（CPUも同様）。
- 精算：本場の加算を更新前の本場数で計算、リーチ棒（供託）を和了者が受け取る、新しい対局開始時に点数・局を初期化。
- 三人麻雀のドラ表示牌（1萬→9萬）に対応。
- 未対応: 槍槓、流し満貫、加槓・暗槓、ダブロン（複数ロン）の優先処理。

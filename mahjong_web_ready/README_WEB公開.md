# 友達とリーチ麻雀 — Web公開用

## Renderで公開する設定
- Runtime: Node
- Build Command: `npm install`
- Start Command: `npm start`

このフォルダの中身をGitHubリポジトリの一番上（root）にアップロードしてください。
`package.json` と `server.js` がリポジトリ直下にある必要があります。
Renderで New + → Web Service → GitHubリポジトリを選び、上記コマンドでデプロイします。
デプロイが成功すると `https://....onrender.com` のようなURLが発行されます。そのURLを友達に共有してください。

## 注意
無料プランやサービス側の制限、初回起動時の待ち時間などは変更される場合があります。
この麻雀アプリは試作版です。公開前に複数端末で動作確認してください。
